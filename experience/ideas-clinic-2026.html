UW DataHub — backend

Another co-op and I rebuilt datahub.uwaterloo.ca, a PhD researcher's campus environmental-sensor platform — I took the backend. The interesting problem is that campus sensors don't share one interface, so a lot of the work was writing an API for sensors that don't have one:

  • Some sources expose REST APIs I can poll and ingest directly.
  • Some hide their data behind a portal, where URL manipulation or replaying the front end's own requests turns the export endpoint into a usable API.
  • Others only send data out by email — so I built automation that parses those emails and folds them into the same pipeline, removing the manual step entirely.
