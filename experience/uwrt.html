Design Team · Jun 2026 – Present · Ongoing

Firmware Developer · UW Robotics Team

STM32 communications for the team's Mars rover: working micro-ROS messaging over serial, with Ethernet integration and debugging in progress.

  • STM32 NUCLEO-F439ZI
  • micro-ROS
  • FreeRTOS
  • USART3 / DMA
  • LwIP / UDP
  • RMII Ethernet
  • NVIDIA Jetson

The rover architecture

The rover has two NVIDIA Jetsons, one for the arm and one for the rover body. I'm contributing to an STM32 communication interface intended to handle time-sensitive I/O and preprocessing alongside those Ubuntu-based computers. Moving that work onto the microcontroller is an integration goal; timing improvements still need to be measured.

Working serial communication

I established micro-ROS Agent connectivity and message exchange on the STM32 NUCLEO-F439ZI over USB/USART3. The setup integrates FreeRTOS firmware with DMA-backed serial transport, providing a working baseline before changing the transport to Ethernet.

Ethernet integration

  • Configured LwIP/UDP, RMII Ethernet, and static IP addressing for the microcontroller's network interface.
  • Verified basic IP connectivity to the board from both Windows and Ubuntu/WSL during bench testing.
  • Used STM32CubeIDE breakpoints and DMA status registers to inspect Ethernet receive-buffer handling and the firmware's packet path.
  • Used tcpdump to check whether UDP traffic reaches the host while investigating the missing micro-ROS Agent traffic.

Current status

Serial message exchange is working. The Ethernet interface responds to basic connectivity checks, while micro-ROS communication over Ethernet is still being debugged. These tests are on the board-to-computer link; full integration with both rover Jetsons is ongoing.
